> جولة تدقيق كاملة بطلب «الثقة صفر، يجب أن تكون كل معادلة وترابط صحيحة ومطابقة للواقع».
> المنهج: **جرد** كل دالة/معادلة/عتبة ← **تجربة حية** على بيانات Open-Meteo حقيقية ← **مرجع خارجي مستقل** منشور لكل ادعاء فيزيائي/فلكي.

الفرق الجوهري بين ما هو «قابل للإثبات بالمعادلة» وما هو «عتبة سياسة»:

- **الفيزياء والفلك** تُثبَت بالمرجع المستقل واجتازت كلها.
- **عتبات السلامة وأوزان الأنواع** سياسة/أولويات معلنة، لا يمكن إثبات «صحتها» بمعادلة — معايرتها تتطلب سجل مصيد وحوادث ميدانية، وهي معلنة كذلك في نصوص المحرك (لا يُدّعى فيها أكثر مما هي).

## 2) الخطأ الوحيد المكتشف والمُصلح: عصر القمر

كانت دالة `moon_illumination` تبدأ من epoch ثابت (2000-01-06) وتتقدّم بشهر مجمعي **متوسط** ثابت `29.530588853` يوماً. المشكلة: المحاق **الحقيقي** يتحرك حول المتوسط بدالة معادلة مركز القمر (سعة ±6.29° ≈ ±12.5 ساعة) ومصطلحات evection/variation، فتراكم الخطأ إلى **~17 ساعة** في سبتمبر 2026 (المحرك كان يضع محاق 11 سبتمبر عند ~20:37 UTC بدل 03:27 UTC).

**الإصلاح:** استبدال التقدير المجمعي بسلسلة Meeus المختصرة (elongation قمر–شمس بسبعة حدود: معادلة مركز القمر + evection + variation + annual + reduction). الدقة الناتجة ≈0.1° ≈ **15 دقيقة** توقيت.

**التحقق مقابل مراجع منشورة (starwalk.space سبتمبر 2026):**

| الحدث الفلكي | المرجع المنشور | المحرك (بعد الإصلاح) | الفرق |
|---|---|---|---|
| تربيعة أخيرة | 4 سبتمبر 07:51 UTC | elongation 269.98° (≈270) | ~دقائق |
| **محاق** | 11 سبتمبر 03:27 UTC | elongation 359.91° (≈0) | ~دقائق |
| تربيعة أولى | 18 سبتمبر 20:44 UTC | elongation 90.12° (≈90) | ~دقائق |
| **بدر** | 26 سبتمبر 16:49 UTC | elongation 179.98° (≈180) | ~دقائق |

وإضاءة 14 سبتمبر عند الظهر = 12.3% (المحرك عند منتصف اليوم)، وهي نفس قيمة «المرجع المستقل ~12.2%» التي كانت تُظهر فرقاً في الجولة السابقة — أي أن «الفرق» السابق كان من عصر القمر، وقد زال.

> ملاحظة: الإضاءة تُقيَّم عند 12:00 UTC لليوم المدني (لحظة تمثيلية)، وهذا موثق في التوقيع. يبقى الاستخدام كما كان: قرينة ضوء ليلي منخفضة الوزن معلنة، لا تمس القرار الثنائي ولا عتبات السلامة ولا تصنيف الحيّة/المات (D9).

## 3) الجرد الكامل

### 3.1 فيزياء مُتحقق منها تجريبياً (كلها PASS مقابل المرجع)

| المعادلة | المرجع المستقل | نتيجة التجربة |
|---|---|---|
| عقدة → كم/س (×1.852) وعكسها | التعريف الدولي | 10 kn = 18.52 كم/س ✓ |
| كم/س → م/ث (÷3.6) | التعريف | 36 = 10.0 م/ث ✓ |
| طول الموجة العميقة L0 = gT²/(2π) | النظرية الخطية | T=6s ⇒ 56.188 م (مرجع 56.19) ✓ |
| الانحدار Hs/L0 | النظرية الخطية | 1/56.19 = 0.01780 ✓ |
| التشتت ω² = g·k·tanh(kh) (Newton) | العلاقة التشتتية | مطابق عند h=1.5/10/50 م بدقة 1e-9 ✓ |
| السرعة المدارية القاعية Ub = π·Hrms/(T·sinh(kh)) مع Hrms=Hs/√2 | النظرية الخطية + فرض رايلي | Ub=0.5119 م/ث = المرجع ✓ |
| وكيل طاقة الموج H²T | ∝ P=(ρg²/64π)·Hs²·T | H=2,T=8 ⇒ 32.0 ✓ |
| الجرّ الجانبي ∝ sin(2α) | إجهاد الإشعاع Sxy | أعظمي عند 45°، صفر عند 0°/90° ✓ |
| حصة النظام الأضعف = H²_الأضعف/ΣH² | طاقة ∝ H² | متساويان ⇒ 0.5 ✓ |
| إجهاد الريح τ = ρ·Cd·U² | معادلة السحب القياسية | U=10 ⇒ 0.1470 Pa ✓ |
| معامل السحب Cd | قيم منشورة فوق البحر | 0.00120–0.00212 ضمن [0.0008, 0.003] ✓ |
| تماسك الاتجاه R = |ΣU·e^{iθ}|/ΣU | الإحصاء الدائري | اتجاهات متطابقة ⇒ R=1 ✓ |
| المتوسط الدائري الموزون بالسرعة | atan2 للمجموع المتجهي | (0°,90°) متناظر ⇒ 45° ✓ |
| معامل الهبة = هبة/مستمرة مع حجب قرب الهدوء | تعريف النسبة | 30/20 = 1.5؛ تحت 5 كم/س ⇒ None ✓ |

### 3.3 اصطلاحات الاتجاه (كلها PASS)

- ريح/موج «من» جهة البحر = بحرية/مباشرة، «من» البر = برّية/غير متسقة ✓
- تيار «نحو» جهة البحر = cross +1 (بحراً)، نحو الشاطئ = −1 ✓ (اتجاه التيار في Open-Meteo = جهة الذهاب، عكس الريح/الموج)
- المركبة الشاطئية = v·cosΔ؛ الريح البرّية تعطي شاطئية سالبة ✓
- الفرق الدائري 350°↔10° = 20° (وليس 340°)؛ الموقّع في [−180,180) ✓

### 3.4 المد من سلسلة مستوى البحر (أرضية اصطناعية معروفة — كلها PASS)

- معدل المستوى = مشتقة الفروق المركزية: ذروة جيبية 0.8 م/فترة 12.42س ⇒ 0.388 م/س (مرجع نظري 0.405) ✓
- تصنيف صاعد/هابط/ركود مطابق لإشارة المشتقة (48 ساعة، صفر مخالفات) ✓
- كشف القمم/القيعان: قمتان وقاعان في 24 ساعة جيبية ✓
- مدى اليوم ≈ سعة المنحنى (1.592 م مقابل 1.6) ✓
- تصنيف حيّة/مات = نسبة المدى إلى الوسيط (1.6/1.0 ⇒ حيّة) ✓ — محسوب من المدى الفعلي **لا** من طور القمر (وثق ذلك D9)

### 3.5 جغرافية الساحل التونسي (كلها PASS)

بنزرت→bizerte_tunis · قليبية→cap_bon_hammamet · المنستير→sahel · قابس→gabes · جربة→south · نطاق خليج قابس للمد العالي ✓

### 3.6 البيانات الحية (Open-Meteo حقيقي، تونس 2026-09-15 — كلها PASS)

ريح 5.8–18.0 كم/س · موج 0.26–0.52 م · حرارة سطح البحر 29.3–29.5°م · ضغط 1017–1020 hPa · أشعة فوق بنفسجية 0–6.8 · مستوى سطح البحر −0.46 إلى −0.23 م — كلها ضمن المجالات الفيزيائية المحلية.

### 3.7 الاتساق الداخلي الشامل (كلها PASS)

- هوية المركبات √(V⊥²+V∥²) = V (أقصى انحراف 0.005 كم/س = تقريب JSON لخانتين) ✓
- إعادة حساب H²T = المشتق (ضمن تقريب 4 خانات) ✓
- السرعة المدارية تتناقص مع العمق (Ub(1.5م)=0.370 ≥ Ub(5م)=0.088) ✓
- نطاق السرعة المعروض يطابق إعادة الحساب عند العمقين ✓
- عامل [1.11] يحمل نفس المتوسط الدائري المعاد حسابه (327°) ✓
- الخلاصة لا تقل عن آليتها الغالبة (قاعدة الشدة القصوى) ✓
- سطر أساس الثقة يعرض المكونات الموزونة ✓
