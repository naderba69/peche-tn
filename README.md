# 🎣 Peche TN

أداة مجانية لدعم قرار صيد **السيرفكاست على الساحل التونسي**. تحسب اتجاه البحر آلياً من خط الساحل مع إبقاء التعديل اليدوي، تجمع توقعات جوية/بحرية ورصد محطة جوية منفصل وسياق Sentinel‑2 ساحلياً متقطعاً، تحلل نشاط البحر السابق حتى 72 ساعة، تمر على العوامل الـ63، ثم تصدر قبل الانطلاق عنواناً ثنائياً فقط: **اذهب** أو **لا تذهب**.

[![CI](https://github.com/naderba69/peche-tn/actions/workflows/ci.yml/badge.svg)](https://github.com/naderba69/peche-tn/actions/workflows/ci.yml)

## مبادئ لا نتنازل عنها

- **قرار رئيسي ثنائي:** العنوان النهائي `go/no_go` فقط، مع `decision_reason_code` يحدد: نافذة اجتازت الحدود الآلية، خطر سلامة، نقص بيانات حرجة، تعطل تنفيذ مرجح، أو تحفظ محافظ. `go` ليس شهادة سلامة ميدانية.
- **السلامة والتنفيذ قبل الفرصة:** نقاط الصيد لا تستطيع تجاوز خطر أو Unknown حرج. ضعف فرصة الصيد وحده لا يمنع نافذة اجتازت الحدود الآلية وقابلة للتنفيذ مبدئياً.
- **لا نخفي نقص البيانات:** غير المتاح يبقى `Unknown`؛ لا يتحول إلى صفر أو «بحر هادئ».
- **الصوفة والعكارة احتمالان غير مانعين وحدهما:** يستعمل المحرك عائلات قرائن تشغيلية مختلفة من طاقة الموج المتراكمة ودفع الريح والتيار والمطر خلال 48 ساعة؛ هي آليات مختلفة وليست أرصاداً أو مصادر مستقلة. لا يدعي وجود الصوفة ولا يخترع NTU؛ حتى التصنيف المرتفع يخفض تقييم التنفيذ ويطلب فحصاً ميدانياً، لكنه لا يلغي نافذة آمنة بلا رصد فعلي.
- **لا نسبة نجاح مزيفة:** `opportunity_score` مؤشر ترتيب منفصل، لا احتمال مصيد.
- **اتجاه قابل للتدقيق:** خوارزمية Overpass المصححة تقبل `0°`، تختار أقرب إسقاط على مقطع الساحل، تنعم المماس، تختار عمود البحر غير المتعارض، وتجرب عدة mirrors. عند الفشل يبقى السهم اليدوي ولا تُخترع قيمة.
- **فصل أنواع الدليل والنماذج:** METAR رصد مطار يحمل الزمن والمسافة و`is_spot_observation=false`؛ Open-Meteo Best Match توقع نموذجي قد يختلف عن GFS27/ECMWF/ICON المنفرد؛ Sentinel‑2 استعادة فضائية يومية غير متزامنة؛ OSM هندسة خريطة.
- **تشخيصات علمية بلا دقة زائفة:** مركبات alongshore موقعة بمحور معلن، إجهاد ريح متجهي بوحدة Pa، تماسك اتجاه دائري، وزاوية/حصة طاقة مكونات الموج. كلها ساعية و`Unknown` عند النقص؛ التشخيصات الجديدة لا تضيف عتبات قرار غير معايرة.
- **63 عاملاً في runtime ledger:** كل عامل يظهر كـ`decision/context/proxy/unknown/excluded` مع القيمة، الأدلة، المبرر وهل أثر في الحسم؛ التسجيل لا يعني التنقيط.
- **Gemini كاتب فقط وبانتظار محدود:** التوليد اختياري بمفتاح المستخدم. يرسل الخادم حزمة سرد مصغرة بلا إحداثيات أو سلاسل رقمية خام، مع إبقاء كل الساعات والعوامل الـ63 ممثلة تصنيفياً؛ الأرقام الكاملة تبقى في التقرير الحتمي. JSON validation وحارس دلالي يمنعان Gemini من تغيير القرار أو كتابة رقم. إعادة التوليد و408/429/5xx تشترك في سقف أربع اتصالات ومهلة كلية 40 ثانية، ويمكن للمستخدم إلغاء الانتظار فوراً.

> ⚠️ Peche TN دعم قرار، وليس نشرة ملاحة أو ضمان سلامة/صيد. النموذج لا يرى كسرة الشاطئ أو الصخور المغمورة أو الصوفة أو العكارة أو التيار الساحبي فعلياً. عاين البحر والمخرج واعمل رمية اختبارية قبل نصب العتاد.

## Full-stack احترافي بتكلفة صفر

```text
app/ + components/ + lib/  Next.js 16 + React + TypeScript — واجهة RTL/PWA
api/index.py               Vercel Python entrypoint الاختياري
apps/api/src/spotdata/     FastAPI + Pydantic — محرك القرار العلمي
deploy/render_app.py       مدخل Render لنطاق واحد
Dockerfile + render.yaml   بناء Next static وتشغيل الخدمة الكاملة
requirements.txt           اعتمادات Python الدنيا
apps/api/tests/            اختبارات domain وAPI وcache بلا شبكة
public/                     أيقونات PWA وService Worker وصفحة سلامة offline
docs/                      المنهجية، التدقيق والمعمارية
```

- **الواجهة:** Next.js، TypeScript، MapLibre، CSS responsive من دون CDN أو خطوط خارجية.
- **تجربة الاستخدام:** مساحة «تقرير بقعة» مستوحاة من رحلة المشروع الأصلي، خريطة مفتوحة افتراضياً وإعدادات واضحة وزر واحد يفتح القرار والتقرير تلقائياً، من 320px إلى الشاشات العريضة.
- **المحرك:** Python، FastAPI، Pydantic.
- **البيانات:** Open-Meteo كتوقعات، AviationWeather.gov كرصد محطة، OpenStreetMap Overpass لهندسة الساحل، وCopernicus Marine WMTS لسياق Sentinel‑2 TUR/FNU وSPM وCHL؛ كلها بلا مفتاح.
- **التقرير الاختياري:** Google Gemini المباشر بمفتاح المستخدم وقت التشغيل؛ لا سر في المشروع أو منصة النشر.
- **النشر الأساسي:** خدمة Docker واحدة على Render؛ `/` للواجهة و`/api/*` لـ FastAPI من النطاق نفسه. يبقى Vercel مساراً اختيارياً.
- **التكلفة:** لا Database ولا خدمة مدفوعة مفروضة؛ الخطة المجانية في Render تنام عند الخمول، واستخدام Gemini خاضع لحصة حساب المستخدم في Google AI Studio.

## ما تعرضه الواجهة

- خريطة الساحل التونسي واختيار الموقع بالنقر أو GPS.
- حساب اتجاه البحر تلقائياً بعد GPS أو اختيار Spot، مع زر إعادة حساب وتعديل يدوي. تظهر النتيجة والمماس ومسافة الساحل وخادم Overpass ونصف قطر البحث والثقة.
- الاتجاه هو bearing من نقطة الوقوف إلى عرض البحر؛ جهتا الريح والموج هما **جهة القدوم**، والتيار هو جهة الحركة `towards`، وتظهر المركبات المحسوبة.
- تاريخ من اليوم إلى سبعة أيام، خبرة الصياد، نوع الوقوف، النوع المستهدف ومدة الحصة.
- قرار رئيسي: `go | no_go` فقط وبالعربية **اذهب / لا تذهب**؛ تبقى `caution/unknown` حالات ساعية داخلية ترفع الحسم المحافظ ولا تظهر كعنوان ثالث.
- لوحة رصد فعلي تعرض أقرب محطة METAR، المسافة والعمر والقيم الخام والفروق مع ساعة النموذج؛ الرصد الأبعد من 75 كم للمقارنة فقط، والأقدم من 120 دقيقة أو الأبعد من 150 كم لا يدخل القرار.
- فحص قابلية ميدانية يوضح تثبيت الخط واحتمالي الصوفة والعكارة والتيار الساحبي، وعدد عائلات القرائن التشغيلية المختلفة وتغطية 48 ساعة، مع ثقة وحدود منفصلة؛ لا تُعامل العائلات كأرصاد أو مصادر مستقلة.
- أفضل ثلاث نوافذ غير متداخلة وفترات يجب تجنبها؛ الخطر المرتبط بساعة لا يلوّث بقية اليوم، وترتيب النوافذ يدخل أضعف قابلية تنفيذ ساعية.
- Timeline ساعة بساعة، مع `antecedent_hours` الخام المطبعة حتى 72 ساعة ومشتقات 48 ساعة: Hs²T·h، ساعات النشاط، دفع الريح نحو الشاطئ، نقل التيار، المطر والتغطية.
- رسم مستوى البحر وقممه/قيعانه النموذجية.
- المصادر والحدود وسبب الثقة.
- cache متصفح وcache للتوقع داخل ذاكرة عملية الخادم لمدة عشر دقائق؛ طبقة Sentinel‑2 اليومية لها cache ست ساعات لتقليل الطلبات العامة.
- حالات تحميل وخطأ واضحة، وتنبيه يمنع خلط النتيجة القديمة بتفاصيل حصة عُدّلت لاحقاً.
- مشاركة/طباعة القرار، أحجام لمس مناسبة، safe areas، وتجهيز مخصص للطباعة.
- قائمة تحقق ميدانية من 12 نقطة تتصفّر بعد 6 ساعات، وتغطي البرق والكسرة والتلوث والقناديل والسباحين/الشباك والطعم والعتاد والوصول ورمية اختبار، مع تنبيه واضح إذا خالف الواقع التوقع.
- تنبيه فوري عند انقطاع الشبكة وصفحة سلامة مستقلة تعمل دون اتصال؛ الـService Worker لا يخزن قرارات أو استجابات API قديمة.
- تقرير حتمي كامل قابل للنسخ وتنزيل TXT والطباعة، وسرد Gemini اختياري من JSON منظم. إدخال المفتاح مخفي، مع تحذير وحفظ محلي واختبار وحذف.

## التقرير الميداني الاحترافي

بعد كل تحليل يفتح التقرير الحتمي تلقائياً مع زر لإخفائه أو إظهاره وقفزة إلى Gemini الاختياري. يجمع التقرير الملخص التنفيذي، رصد المحطة الفعلي إن توفر مع مسافته وحدوده، سياق Sentinel‑2 مع التاريخ والعمر والمسافة والدقة والوحدات، الشروق والغروب، حركة مستوى البحر، النوافذ المقترحة، قابلية التنفيذ الميداني، التفكيك الزمني، ميزان العوامل، الإرشاد الميداني، والأرقام والمشتقات والمعادلات لكل ساعة مع النطاقات والقمم والتغطية والمصادر.

حتى يبقى التقرير مطابقاً لما تسمح به البيانات:

- يعرض **مؤشر فرصة** لا «نسبة نجاح» أو احتمال مصيد.
- يعرض السويل وموج الريح منفصلين، ويصف الصوفة والعكارة والتيار الساحبي كاحتمالات لا رصد فعلي، ويعرض عدد عائلات القرائن التشغيلية وتغطية 48–72 ساعة.
- لا يحوّل العبور القمري أو solunar إلى مواقيت مدّ مزعومة؛ القمم والقيعان تأتي من سلسلة مستوى البحر النموذجية.
- لا يخترع مسافة رمي أو وزن رصاص أو طعماً مثالياً من دون بيانات القصبة والخيط والقاع والفرائس المحلية.
- يعرض الفترات الناقصة كغير متوفرة، ويستعمل أضعف ثقة داخل النافذة كقراءة محافظة.
- يحفظ الإحداثيات واتجاه البحر وprovenance الساحل ونوع الوقوف والخبرة والنوع المستهدف.
- يعرض ledger تنفيذي لكل العوامل الـ63، لا عدادات التغطية فقط.

التقرير الحتمي لا يمر عبر LLM ويبقى متاحاً دائماً. اختيارياً، يمكن إدخال مفتاح Gemini من الواجهة لتوليد سرد عربي: يبني الخادم Evidence Packet مصغرة مخصصة للكاتب، بلا إحداثيات أو raw history أو أرقام الساعات، مع إبقاء التصنيفات الزمنية وكل العوامل الـ63 وUnknown وحدود المصادر. يطلب JSON وفق schema مقيد، يتحقق منه، ويركب القرار والأرقام بنفسه. يمنع الحارس السرد من كتابة أرقام أو إعادة أمر القرار. يقبل المحلل غلاف JSON الصالح الشائع ويتجاهل أجزاء التفكير، ويصنف القطع عند بلوغ حد الخرج؛ ويجوز إعادة توليد بنيوية واحدة ضمن حد عالمي صارم من أربع اتصالات ومهلة كلية 40 ثانية. يمكن إيقاف الزر أثناء الانتظار، ويعيد timeout الواجهة إلى التقرير الحتمي. راجع [سياسة المفتاح](docs/local-api-policy.md).

## السلوك دون اتصال

بعد أول زيارة ناجحة في الإنتاج، يسجل المتصفح Service Worker صغيراً يخزن فقط صفحة السلامة المستقلة وأيقوناتها. إذا انقطعت الشبكة والتطبيق مفتوح يظهر تنبيه بأن القرار لا يمكن تحديثه ببيانات جديدة، وإذا فُتح رابط جديد تظهر قائمة تحقق ميدانية بدل إعادة عرض توقع قديم.

- لا تُخزن مسارات `/api/*` في Service Worker.
- لا يُعتبر وضع offline وضعاً لإصدار قرار صيد.
- قائمتا الواجهة وصفحة offline تحفظان نفس التقدم محلياً فقط وتُصفّرانه تلقائياً بعد 6 ساعات.
- رقم الحماية المدنية الظاهر في صفحة السلامة: **198** ([مرجع رسمي لأرقام الطوارئ في تونس](https://tn.diplomatie.gouv.fr/fr/urgence)).

## API

| الطريقة | المسار | الوظيفة |
|---|---|---|
| `GET` | `/api/health` | صحة الخدمة وإحصاءات cache داخل النسخة الدافئة |
| `GET` | `/api/methodology` | مبادئ القرار وملخص تغطية المصفوفة |
| `GET` | `/api/methodology/factors` | سجل تدقيق العوامل الـ63 وحالة كل عامل |
| `GET` | `/api/docs` | Swagger |
| `POST` | `/api/v1/spots/orientation` | يحسب عمود الساحل المصحح عبر mirrors من Overpass |
| `POST` | `/api/v1/decisions/forecast` | يجلب التوقعات وMETAR ثم يصدر قراراً ثنائياً |
| `POST` | `/api/v1/decisions/evaluate` | يقيّم Dataset جاهزاً بلا شبكة |
| `POST` | `/api/v1/gemini/verify` | يختبر مفتاحاً وقتياً من header بلا تخزين |
| `POST` | `/api/v1/reports/gemini` | يولد سرد JSON مقيداً؛ القرار والأرقام حتمية |

مثال الطلب:

```json
{
  "location": {
    "latitude": 36.4561,
    "longitude": 10.7389,
    "name": "نابل"
  },
  "target_date": "2026-09-08",
  "spot": {
    "seaward_orientation_deg": 90,
    "orientation_source": "manual",
    "shore_type": "sandy",
    "exposure": "open"
  },
  "angler": {
    "experience": "intermediate",
    "target_species": "general",
    "session_hours": 3
  }
}
```

الاستجابة الحالية `schema_version: 3.9` و`engine_version: 1.6.8`. `decision` ثنائي ومعه `decision_reason_code`. تشمل `antecedent_hours` حتى 72 ساعة خام مطبعة، والمشتقات الساعية الموقعة وإجهاد الريح والتماسك الدائري وتشخيص مكونات الموج، و`factor_assessments` بطول 63، وprovenance والمصادر وMETAR المنفصل و`coastal_water_context` الاختياري من Sentinel‑2 (الآن مع `sea_surface_temperature_c` اختياري)، ومصفوفات مواسم الأنواع المشتقة من دراسات علمية منشورة لتونس والمتوسط مع `sources_ar` لكل نوع، وبُعد «حالة البحر × الشهر» لكل نوع، وقائمة `trip_ruin_factors` الخمسة (صوفة/تعكر/قناديل/موجة حر بحرية/حطام) بقاعدة أدلة صارمة: الدليل المؤكد يمنع (`trip_ruin_confirmed`) والتنبؤ يبقى تنبيهاً وما لا مصدر له يبقى Unknown، وقائمة `species_activity` التقريرية (مؤشر نشاط نسبي 0‑100 لكل نوع × فترات اليوم وساعة بساعة، `is_probability: false` دائماً). التشخيصات الجديدة والسياق الفضائي ومؤشر النشاط لا يغيران القرار أو السلامة أو قابلية التنفيذ أو مؤشر الفرصة أو الثقة إلا عبر قنوات الإثبات المؤكد الموثقة. تعامل مع تغيير schema كتغيير عقد API لا كحقل تجميلي.

## مفتاح Gemini من الواجهة

الموصلات العلمية الأساسية مجانية وبلا مفتاح. Gemini استثناء اختياري يملكه المستخدم: لا يوضع مفتاح في bundle أو Git أو ZIP أو Render أو Vercel. تعرض الواجهة مخاطر `localStorage` وتطلب الموافقة قبل الحفظ، وتوفر الإخفاء والاختبار والحذف. يرسل المفتاح وقت الطلب فقط عبر HTTPS ولا يخزنه أو يسجله FastAPI.

لا تدّعي الوثائق أن `localStorage` آمن؛ استعمل مفتاحاً مقيداً وقابلاً للإلغاء وعلى جهاز شخصي. التفاصيل واختبارات منع التسرب: [`docs/local-api-policy.md`](docs/local-api-policy.md).

النجاح الحقيقي هو `ALL PASS`. أول طلب بعد نوم الخطة المجانية قد يستغرق قرابة دقيقة.

يبقى Vercel مساراً اختيارياً موثقاً في [`VERCEL.md`](VERCEL.md). أزيلت منه قواعد API المخصصة التي فشلت حياً؛ `api/index.py` يعتمد file-system routing الأصلي فقط.

## معنى «تكلفة صفر»

المشروع لا يفرض خدمة مدفوعة، ويعمل أساسياً على Render Free وOpen-Meteo وAviationWeather.gov وOverpass وCopernicus Marine WMTS ضمن حدود الخدمات العامة. خدمة Render المجانية تنام عند الخمول ولا توفر SLA؛ هذا لا يعني استعمالاً غير محدود. Gemini اختياري ويستهلك حصة مفتاح المستخدم في Google AI Studio؛ التطبيق الحتمي يعمل بدونه. راجع شروط كل مزود قبل استعمال تجاري أو انتشار كبير.

## الجودة الحالية

- **161** اختبار Python للمحرك وAPI وcache وMETAR والمصالحة وOverpass وGemini وسجل العوامل بلا اعتماد على الإنترنت؛ التغطية الحالية **90.75%**.
- Coverage أدنى مفروض محلياً وفي CI: **85%**.
- Ruff + mypy strict.
- ESLint + TypeScript strict + production build.
- **20** اختبار Playwright E2E على Chromium، تشمل خمس فئات شاشة، نافذة تعبر منتصف الليل، كشف HTML 500 من بوابة Vercel، Overpass، إدارة مفتاح Gemini والتقرير المنظم، والتنزيل والسلامة offline.
- GitHub Actions يشغل backend وfrontend واختبارات التجاوب في كل push وPull Request.

## خارطة الطريق التالية

1. إثبات محطات موج/مد/تيار تونسية متاحة فعلياً عبر EMODnet/Copernicus/IOC قبل إضافة أي موصل بحري in-situ؛ غياب الرصد يبقى `Unknown`.

3. قاعدة بقع تونسية GeoJSON وباتيمتريا ساحلية موثقة بدل presets أولية.
4. مقارنة عائلات نماذج مستقلة وسجل رحلات/مصيد مجهول الهوية لمعايرة المؤشر، مع بقاء السلامة rule-based.
