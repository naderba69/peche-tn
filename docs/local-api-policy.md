# سياسة موصلات API والمفاتيح — Peche TN

## المعمارية الحالية

كل طلب من الواجهة يذهب إلى مسار same-origin تحت `/api/*`. FastAPI يتولى التحقق وتوحيد الوحدات ووسم المصدر:

- Open-Meteo Weather وMarine: توقعات نموذجية، لا رصد شاطئي.
- AviationWeather.gov: METAR في محطة مطار مع المسافة والعمر، لا داخل البقعة.
- OpenStreetMap Overpass: هندسة خط الساحل فقط لحساب اتجاه البحر، عبر عدة mirrors.
- Google Gemini Developer API: **كاتب اختياري فقط**؛ لا يدخل مسار الحساب أو الحسم.

لا يحتاج النشر إلى سر في Vercel. `GEMINI_BASE_URL` و`GEMINI_MODEL` إعدادان غير سريين ولهما قيم افتراضية.

## الاستثناء المقصود لمفتاح Gemini وقت التشغيل

بناءً على تصميم المنتج، يدخل المستخدم مفتاح Google AI Studio في واجهة التقرير. السياسة الدقيقة:

1. الحقل `password` ومخفي افتراضياً، مع زر إظهار صريح.
2. تظهر مخاطر `localStorage` قبل الحفظ، ويجب تأكيد الموافقة.
3. عند اختيار الحفظ الدائم، يخزن المتصفح المفتاح تحت `peche-tn:gemini-api-key` في `localStorage` على ذلك الأصل.
4. `localStorage` **ليس خزنة أسرار**: يستطيع سكربت يعمل في الأصل نفسه، إضافة متصفح واسعة الصلاحية، أو مستخدم الجهاز الوصول إليه. يُنصح بمفتاح مقيد وقابل للإلغاء وعلى جهاز شخصي.
5. زر «اختبر» أو «ولّد» فقط يرسل المفتاح مؤقتاً عبر HTTPS في `X-Gemini-API-Key` إلى FastAPI؛ لا يوجد توليد تلقائي.
6. FastAPI يمرره إلى Google في `x-goog-api-key`. لا يضعه في body أو response أو cache أو provenance أو سجل التطبيق، ولا يكتبه على القرص أو في قاعدة بيانات.
7. زر «احذف» يمسح القيمة من `localStorage` والحالة الحالية.
8. لا يوضع المفتاح في `.env*` أو Vercel أو Git أو ZIP أو `NEXT_PUBLIC_*`.

الخادم يعيد `Cache-Control: no-store`. ينبغي الانتباه إلى أن Google يستقبل **حزمة سرد مصغرة** وفق شروط خدمته، وأن بنية الاستضافة/المتصفح خارج كود Peche TN قد تخضع لسجلاتها وسياساتها الخاصة.

## حدود سلطة Gemini وتقليل البيانات

FastAPI يستقبل `DecisionResponse` الكامل من الواجهة للتحقق والتركيب، لكنه لا ينسخه كاملاً إلى Google. حزمة الكاتب المصغرة:

- لا ترسل إحداثيات البقعة أو المحطة أو بكسل Sentinel‑2.
- لا ترسل الساعات السابقة الخام أو الأرقام الخام لكل ساعة أو نص METAR الخام.
- تحفظ ترتيب الساعات كتسلسل تصنيفي: جزء اليوم، السلامة، قابلية التنفيذ، علاقة الريح، ورود الموج وحالة الماء النموذجية.
- تحفظ كل تقييمات العوامل الـ63 بصورة مصغرة، وUnknown الصريح، وحدود المصادر والرصد وSentinel‑2.
- لها حد صلب قدره 64 kB؛ الأرقام والمعادلات والتفاصيل الكاملة تبقى في التقرير الحتمي المركب على الخادم.

حدود التنفيذ والسلطة:

- المحرك الحتمي وحده يصدر القرار والأرقام.
- Gemini يعيد JSON سردياً وفق schema؛ يتحقق منه Pydantic على الخادم، ولا تتجاوز معالجة JSON غير الصالح إعادة توليد بنيوية واحدة ضمن سقف أربع اتصالات بالمزود.
- تشترك إعادة التوليد وretries في مهلة خادم كلية 40 ثانية؛ للمتصفح cutoff قدره 42 ثانية وزر إلغاء فوري، لذلك لا يبقى spinner بلا حد.
- السرد ممنوع من كتابة أرقام أو أوامر «اذهب/لا تذهب»؛ الخادم يرفض المخالفة.
- القالب النهائي يعرض الأرقام والقرار من `DecisionResponse` فقط.
- أي فشل أو رفض أو حد استخدام يعيد الواجهة إلى التقرير الحتمي الكامل.

## إعداد التطوير المحلي

```bash
cp .env.example .env.local
chmod 600 .env.local
make dev-api
# وفي جلسة ثانية
make web-dev
```

`PECHE_TN_API_ORIGIN` يُقرأ في Next.js محلياً ليحوّل `/api/*` إلى FastAPI. `.env.local` مستبعد من Git وZIP. لا تضع مفتاح Gemini فيه؛ أدخله من الواجهة كما يفعل المستخدم النهائي.

## معيار أي موصل جديد

يجب أن يحدد ويختبر:

- نوع البيانات: رصد مباشر أو توقع نموذجي أو هندسة خريطة أو proxy.
- زمن القياس/التوقع والجلب والعمر والمنطقة الزمنية.
- إحداثيات المحطة/الخلية والمسافة والتمثيل المكاني.
- الوحدة الأصلية والتحويل وQC وسياسة القيمة المفقودة.
- mirrors/retries محدودة، timeout، cache، وفشل آمن يعيد Unknown.
- lineage: الخام ← المصدر ← التحويل/المعادلة ← المشتق ← سبب القرار.
- اختبارات fixtures بلا شبكة وحدود هندسية وزمنية.

الرصد الفضائي لا يسمى قياساً داخل Spot، ومحطة المطار لا تنسب إلى الشاطئ، والتوقع لا يسمى رصداً، وهندسة OSM لا تسمى مسح بوصلة.

## فحص منع الأسرار قبل الرفع

```bash
git status --short
git check-ignore .env.local

grep -RInE "AIza[[:alnum:]_-]{20,}|NEXT_PUBLIC_.*(KEY|SECRET|TOKEN)" \
  --exclude-dir=node_modules --exclude-dir=.next --exclude-dir=.git . || true
```

ينبغي أن يؤكد `git check-ignore` استبعاد `.env.local`، وألا يظهر مفتاح فعلي. لا تلصق المفتاح في أوامر shell أو screenshots أو logs أثناء الفحص.
